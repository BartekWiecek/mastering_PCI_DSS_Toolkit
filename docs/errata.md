# Errata and updates

This page records published corrections to the reader materials. The initial RC8 package is a preview; final edition compatibility is not yet assigned.

## Known limitations of RC8 preview

- The calendar is a planning aid, with full semantic coverage review still open.
- The local tests use synthetic fixtures. The browser end-to-end test has not been completed for RC8.
- A workbook or lab result is not a real PCI DSS assessment or eligibility conclusion.

No additional errata have been published here yet. Report reproducible issues through [GitHub Issues](https://github.com/BartekWiecek/mastering_PCI_DSS_Toolkit/issues), identifying the Toolkit version and file or section. Do not submit confidential data, cardholder data, credentials or assessment reports.
